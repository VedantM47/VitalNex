Same rules as `docs/i18n_review.md` (D-15): every Hindi (HI) and Marathi (MR) string with medical or safety
meaning is **pending** until a human reviewer confirms it. These were written by Claude Code and have **not** been
checked by a native-speaker clinician. This file is separate from `docs/i18n_review.md` only to avoid edit
conflicts during parallel work; merge it in when convenient.

When a reviewer confirms a row, change its status to `confirmed (<name>, <date>)`. If the wording changes, update
the source file and this list together.

Status key: `pending` = not reviewed · `confirmed` = reviewed and accepted.
